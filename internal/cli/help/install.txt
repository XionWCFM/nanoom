Install dependencies

Usage: nanoom install [OPTIONS]

Options:
      --package-manager <PACKAGE_MANAGER>
          Package manager to use (auto, pnpm, yarn, npm)
      --filter <FILTER>
          Install these workspaces and their dependency closure
      --filter-file <FILTER_FILE>
          File with a JSON string array of workspace filters for a planned assignment
      --json
          Output a JSON result
  -c, --config <CONFIG>
          Path to nanoom.config.json config file
  -C, --cwd <CWD>
          Working directory
  -v, --verbose...
          Increase verbosity
  -h, --help
          Print help
