Validate and select a Plan v1 assignment

Usage: nanoom plan [OPTIONS] <COMMAND>

Commands:
  select  Validate a Plan v1 file and select one assignment
  help    Print this message or the help of the given subcommand(s)

Options:
  -c, --config <CONFIG>  Path to nanoom.config.json config file
  -C, --cwd <CWD>        Working directory
  -v, --verbose...       Increase verbosity
  -h, --help             Print help
