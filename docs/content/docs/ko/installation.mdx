이 페이지에서는 `nanoom` CLI를 설치하는 세 가지 방법을 보여드립니다. 상황에 맞춰 골라 보세요: 로컬 개발엔 npm(권장), 독립 실행엔 직접 다운로드, CI엔 GitHub Actions 복합 액션.

## 사전 요구사항

- Node.js 18+ — npm 래퍼용입니다. 바이너리 자체는 독립 실행 파일입니다.
- Git — nanoom이 git 히스토리를 읽어 변경점을 감지합니다.

## npm으로 설치

```bash
npm install -D @nanoom/cli
```

래퍼 패키지는 플랫폼별로 `optionalDependency`를 하나씩 선언합니다:

| 패키지 | 플랫폼 |
| --- | --- |
| `@nanoom/cli-linux-x64` | Linux x86_64 |
| `@nanoom/cli-linux-arm64` | Linux arm64 |
| `@nanoom/cli-macos-x64` | macOS Intel |
| `@nanoom/cli-macos-arm64` | macOS Apple Silicon |
| `@nanoom/cli-windows-x64` | Windows x86_64 |

npm은 현재 플랫폼에 맞는 것만 설치하고, `nanoom` 바이너리가 실행될 때 자동으로 찾아 씁니다.

설치 확인:

```bash
nanoom --version
```

## 바이너리 직접 다운로드

[GitHub Releases](https://github.com/XionWCFM/nanoom/releases)에서 아카이브를 받으세요. 모든 에셋에 `.sha256` 체크섬이 붙어 있으니, 압축 풀기 전에 검증하세요:

```bash
curl -fsSL -o nanoom.tar.gz \
  https://github.com/XionWCFM/nanoom/releases/download/v0.2.9/nanoom-macos-arm64.tar.gz
curl -fsSL -o nanoom.tar.gz.sha256 \
  https://github.com/XionWCFM/nanoom/releases/download/v0.2.9/nanoom-macos-arm64.tar.gz.sha256

shasum -a 256 -c nanoom.tar.gz.sha256
tar -xzf nanoom.tar.gz && chmod +x nanoom && ./nanoom --version
```

## GitHub Actions에서 설치

릴리스 태그로 고정한 공개 명령 Action을 사용하세요. 릴리스 체크섬을 검증한 뒤 nanoom을 실행합니다:

```yaml
- uses: XionWCFM/nanoom/.github/actions/affected@v0.2.9
```

## 에디터 자동완성 켜기

JSON 스키마를 생성해 설정 파일에 참조하면, 에디터가 모든 필드를 자동완성하고 검증해 줍니다:

```bash
nanoom schema --output nanoom.schema.json
```

```jsonc
// nanoom.config.json
{
  "$schema": "./nanoom.schema.json"
}
```

VS Code, JetBrains IDE, 스키마를 지원하는 모든 에디터에서 작동합니다.
