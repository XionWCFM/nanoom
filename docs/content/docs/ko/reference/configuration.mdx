---
title: 설정 레퍼런스
description: nanoom.config.json 필드와 검증 규칙
---

`nanoom schema --output nanoom.schema.json`으로 편집기 스키마를 생성할 수 있습니다. 알 수 없는 필드는 거부됩니다.

```json
{
  "$schema": "./nanoom.schema.json",
  "group": {
    "ci": {
      "tasks": ["lint", "test"],
      "rules": [
        { "name": "@repo/app", "isolate": ["test"] },
        { "name": "@repo/e2e", "shard": [{ "task": "test", "shard": 2 }] }
      ]
    }
  },
  "globalDependencies": ["yarn.lock"],
  "workspace": { "include": ["packages/*"], "exclude": [] }
}
```

| 필드 | 필수 | 계약 |
| --- | --- | --- |
| `$schema` | 아니오 | 스키마 경로 또는 URL |
| `group` | 예 | 하나 이상의 이름 있는 그룹 |
| `group.<name>.tasks` | 예 | 비어 있지 않은 고유 작업명 |
| `group.<name>.rules` | 아니오 | 프로젝트명별 고유 규칙 |
| `rule.name` | 예 | 비어 있지 않은 워크스페이스명 |
| `rule.ignore` | 아니오 | 그룹에서 워크스페이스 제외 |
| `rule.isolate` | 아니오 | 격리 항목이 필요한 그룹 작업 |
| `rule.shard` | 아니오 | `{task, shard}` 항목. 개수는 0보다 커야 함 |
| `globalDependencies` | 아니오 | 모든 워크스페이스에 영향을 주는 유효한 glob |
| `workspace.include` | 아니오 | 탐색 glob. 기본값은 `packages/*`, `apps/*` |
| `workspace.exclude` | 아니오 | 탐색 제외 glob |

같은 규칙에서 한 작업을 격리와 샤드로 동시에 지정할 수 없습니다. 규칙의 작업명은 그룹 작업 목록에 있어야 하며, 중복 워크스페이스 패키지명도 거부됩니다.

의존성 간선은 dependencies, devDependencies, peerDependencies, optionalDependencies를 모두 포함합니다. `workspace:`, `link:`, `file:` 선언은 로컬 간선입니다. 레지스트리 선언은 로컬 워크스페이스 버전이 합집합, 비교식, 프리릴리스, 하이픈 범위를 포함한 npm 호환 semver를 만족할 때만 로컬 간선입니다.

변경 워크스페이스는 의존하는 상위 워크스페이스로 전이 확장됩니다. `globalDependencies`가 일치하면 탐색된 모든 워크스페이스가 영향을 받습니다.
