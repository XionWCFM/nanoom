title: Rust 라이브러리 레퍼런스
description: 공개 CLI와 Action을 구현하는 내부 모듈
---

Rust crate는 주로 `nanoom` 바이너리의 구현 라이브러리입니다. 모듈 API 자체는 별도 버전 안정성 계약이 아니며, 지원되는 소비자 계약은 CLI, 설정 스키마, Action 메타데이터, 릴리스 아카이브, npm 패키지입니다.

| 모듈 | 책임 |
| --- | --- |
| `config` | `nanoom.config.json` 파싱과 검증 |
| `workspace` | 패키지 탐색, 로컬 semver 간선 판정, 의존자 구성, 작업 정렬 |
| `git` | 저장소 열기와 명시적 리비전 비교 |
| `affected` | 변경·전역 파일, 의존자 확장, 그룹 규칙, 샤드·격리 매트릭스 적용 |
| `commands` | affected/run/install/status/cache-key CLI 경계 동작 |
| `schema` | 설정 JSON Schema 생성 |
| `error` | 타입화한 사용자 오류와 종료 전달 |

GitHub 이벤트 해석은 `.github/actions/affected/action.yml`의 책임입니다. 이 경계가 Rust 명령에 명시적인 `--base`, `--head`를 전달하며 직접 CLI는 이벤트 환경변수를 추측하지 않습니다.

모듈 변경 시 유효 예제, 잘못된 경계, 원래 회귀를 검사하세요. Action이나 배포가 관련되면 ADR-0002의 릴리스 소비자 픽스쳐 경로도 통과해야 합니다.
