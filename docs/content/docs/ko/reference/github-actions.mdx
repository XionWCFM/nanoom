공개 Action은 릴리스 태그로 고정하세요: `XionWCFM/nanoom/.github/actions/<name>@v0.2.9`. 내부 설치 스크립트도 같은 태그에서 로드되며 `main`을 따라가지 않습니다. 로그는 접힘 없이 입력 → 해석값 → 이유 → 명령 → 결과 → 최종 JSON 순서로 출력됩니다.

## `affected`

```yaml
- id: affected
  uses: XionWCFM/nanoom/.github/actions/affected@v0.2.9
  with:
    cwd: .
    config: nanoom.config.json
```

| 입력 | 기본값 | 설명 |
| --- | --- | --- |
| `version` | `action` | Action ref의 릴리스 태그. 저장소 테스트는 `local` |
| `cwd` | `.` | 소비자 작업 디렉터리 |
| `config` | `nanoom.config.json` | `cwd` 기준 설정 경로 |
| `base`, `head` | 이벤트에서 계산 | 명시적 비교 리비전 |
| `releaseBaseUrl` | `https://github.com` | Nanoom release asset의 HTTPS origin. Enterprise Server가 release를 호스팅할 때만 해당 URL로 설정 |

출력은 `has_change`, `groups`, `result`입니다. `groups`는 설정된 각 그룹을 `{hasChange, matrix}`로 매핑하며, 각 항목은 GitHub 출력 한도를 지키기 위해 `name`, `task`, 선택적인 샤드·격리 필드만 보냅니다. `result`는 비교 커밋과 그룹별 항목 수를 담은 compact canonical summary입니다. Action 경계에서 GitHub 표준 컨텍스트(`before`, `base_ref`, merge-group base SHA)를 해석한 뒤 CLI에 명시적인 리비전을 전달합니다.

`releaseBaseUrl`은 GitHub Enterprise Server에서도 기본적으로 public GitHub를 사용합니다. Enterprise Server에 같은 Nanoom release tag와 asset을 미러링한 경우에만 그 HTTPS URL로 바꾸세요. API/event 해석은 계속 현재 GitHub host를 사용합니다.

## `install`

```yaml
- uses: XionWCFM/nanoom/.github/actions/install@v0.2.9
  with:
    matrix: ${{ toJSON(matrix) }}
    packageManager: yarn
```

`matrix`는 필수이며 단일 항목 또는 `include` 래퍼를 받을 수 있습니다. `packageManager`, `cwd`, `version`, `releaseBaseUrl`은 선택입니다. npm은 필요한 워크스페이스 의존성 폐쇄 집중 설치를 지원하지 않으므로 거부됩니다.

## `run`

```yaml
- uses: XionWCFM/nanoom/.github/actions/run@v0.2.9
  with:
    matrix: ${{ toJSON(matrix) }}
    group: ci
    packageManager: yarn
    monorepoTool: turbo
```

필수 `matrix` 항목이 워크스페이스, 작업, 샤드, 격리 정보를 제공하고, 필수 `group` 입력이 affected 그룹을 지정합니다. `packageManager`, `monorepoTool`, `cwd`, `version`, `releaseBaseUrl`은 선택입니다.

## `status`

```yaml
- uses: XionWCFM/nanoom/.github/actions/status@v0.2.9
  with:
    needs: ${{ toJSON(needs) }}
    affectedJob: affected
    matrixJob: run
    group: ci
    format: markdown
```

`needs`는 필수입니다. 나머지 기본값은 위와 같고 `format` 기본값만 `text`입니다. 이 Action은 CLI를 설치하지 않고 `jq`로 직접 판정합니다. `hasChange=true/matrix=success` 또는 `hasChange=false/matrix=skipped`만 성공하며, 불일치·취소·실패 조합은 모두 실패합니다.

각 Action 매트릭스 항목은 `name`, `task`를 포함합니다. 샤드 항목은 `shard`, `totalShards`, 격리 항목은 `isolate: true`를 추가하고, `run` Action에는 그룹을 한 번 전달합니다. 브랜치 보호에는 최종 `status` 잡을 안정적인 필수 체크로 사용하세요.
