---
title: 빠른 시작
description: 영향받은 워크스페이스 실행 설정과 검증
---

`nanoom.config.json`을 만드세요.

```json
{
  "$schema": "./nanoom.schema.json",
  "group": { "ci": { "tasks": ["lint", "test", "build"] } },
  "globalDependencies": ["yarn.lock", "tsconfig.json"]
}
```

스키마를 만들고 실제 비교를 미리 확인합니다.

```bash
nanoom schema --output nanoom.schema.json
nanoom affected --base main --head HEAD --matrix
nanoom run ci test --all
```

CLI의 `affected`는 명시적 base가 필요합니다. GitHub Actions에서는 공개 `affected` Action이 이벤트 리비전을 해석해 명시적으로 전달합니다.

이어서 [풀 리퀘스트 검사 실행](/ko/docs/how-tos/pr-checks)의 태그 고정 전체 워크플로를 복사하세요. 리프 변경이 의존자를 포함하는 경우, 전역 의존성 변경이 전체를 실행하는 경우, 무관한 변경이 `hasChange=false`와 건너뛴 매트릭스·성공한 status를 만드는 경우를 검증합니다.
