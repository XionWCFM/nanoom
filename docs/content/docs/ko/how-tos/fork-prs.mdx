---
title: 포크 풀 리퀘스트 안전 실행
description: 시크릿 노출 없이 표준 이벤트 리비전 사용
---

일반 풀 리퀘스트와 같은 태그 고정 워크플로를 사용합니다. `affected` Action은 `github.base_ref`, `github.sha`를 해석하고, base ref가 없으면 읽기 전용 저장소 권한으로 가져온 뒤 CLI에 명시적인 리비전을 전달합니다.

```yaml
permissions: { contents: read }
steps:
  - uses: actions/checkout@v4
    with: { fetch-depth: 100 }
  - id: affected
    uses: XionWCFM/nanoom/.github/actions/affected@v0.2.9
```

신뢰할 수 없는 포크 코드를 실행할 때 `pull_request_target`을 사용하지 마세요. 일반 포크 `pull_request`에는 저장소 시크릿이 전달되지 않습니다. install/run을 비공개 토큰 없이 실행하거나 시크릿이 필요한 잡을 동일 저장소 PR로 제한하세요.

비교 히스토리가 없으면 `fetch-depth`를 늘리거나 base 브랜치를 가져오세요. 로컬 재현은 `nanoom affected --base origin/main --head HEAD --matrix`를 사용합니다. CLI 자체는 GitHub 이벤트 환경변수를 추론하지 않습니다.
