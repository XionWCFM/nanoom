---
title: 느린 스위트 샤딩
description: 서로 다른 매트릭스 샤드 생성과 실행
---

```json
{
  "group": {
    "ci": {
      "tasks": ["test:e2e"],
      "rules": [{
        "name": "@repo/web",
        "shard": [{ "task": "test:e2e", "shard": 4 }]
      }]
    }
  }
}
```

이 설정은 `shard: 1..4`, `totalShards: 4`인 네 항목을 생성합니다. 전체 항목을 Action에 전달하세요.

```yaml
- uses: XionWCFM/nanoom/.github/actions/run@v0.2.3
  with:
    matrix: ${{ toJSON(matrix) }}
```

작업은 `NANOOM_SHARD_INDEX`, `NANOOM_SHARD_TOTAL`을 받습니다. 테스트 러너의 샤드 플래그에 연결하세요. 두 CLI 샤드 플래그는 함께 사용하고 유효한 1 기반 범위여야 합니다.

같은 규칙에서 한 작업을 샤드와 격리로 동시에 지정할 수 없습니다. 모호한 설정은 검증 단계에서 거부됩니다. 회귀 완료조건은 녹색으로 건너뛴 매트릭스가 아니라 예상한 모든 샤드 잡의 실제 실행과 성공입니다.
