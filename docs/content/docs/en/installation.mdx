This page shows you how to install the `nanoom` CLI. Pick one of three ways: npm (recommended for local development), a direct binary download, or the GitHub Actions composite action.

## Requirements

- Node.js 18+ — only for the npm wrapper. The binary itself is self-contained.
- Git — nanoom reads your git history to detect changes.

## Install with npm

```bash
npm install -D @nanoom/cli
```

The wrapper package declares one `optionalDependency` per platform:

| Package | Platform |
| --- | --- |
| `@nanoom/cli-linux-x64` | Linux x86_64 |
| `@nanoom/cli-linux-arm64` | Linux arm64 |
| `@nanoom/cli-macos-x64` | macOS Intel |
| `@nanoom/cli-macos-arm64` | macOS Apple Silicon |
| `@nanoom/cli-windows-x64` | Windows x86_64 |

npm installs only the matching package; the `nanoom` bin resolves it at runtime.

Verify the install:

```bash
nanoom --version
```

## Download a binary

Download an archive from [GitHub Releases](https://github.com/XionWCFM/nanoom/releases). Every asset ships with a `.sha256` checksum, so verify before extracting:

```bash
curl -fsSL -o nanoom.tar.gz \
  https://github.com/XionWCFM/nanoom/releases/download/v0.2.9/nanoom-macos-arm64.tar.gz
curl -fsSL -o nanoom.tar.gz.sha256 \
  https://github.com/XionWCFM/nanoom/releases/download/v0.2.9/nanoom-macos-arm64.tar.gz.sha256

shasum -a 256 -c nanoom.tar.gz.sha256
tar -xzf nanoom.tar.gz && chmod +x nanoom && ./nanoom --version
```

## Install in GitHub Actions

Use a public command Action pinned to a release tag. It verifies the release checksum before invoking nanoom:

```yaml
- uses: XionWCFM/nanoom/.github/actions/affected@v0.2.9
```

## Enable editor autocomplete

Generate the JSON schema and reference it from your config. Your editor then autocompletes and validates every field:

```bash
nanoom schema --output nanoom.schema.json
```

```jsonc
// nanoom.config.json
{
  "$schema": "./nanoom.schema.json"
}
```

This works in VS Code, JetBrains IDEs, and any schema-aware editor.
