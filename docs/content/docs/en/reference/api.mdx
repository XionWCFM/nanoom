---
title: Rust library reference
description: Internal modules behind the public CLI and Actions
---

The Rust crate is primarily an implementation library for the `nanoom` binary. Its public modules are not a separately versioned stability promise; the CLI, configuration schema, Action metadata, release archives, and npm packages are the supported consumer contracts.

| Module | Responsibility |
| --- | --- |
| `config` | Parse and validate `nanoom.config.json` |
| `workspace` | Discover packages, classify local semver edges, build dependents, sort tasks |
| `git` | Open repositories and compare explicit revisions |
| `affected` | Apply changed/global files, dependent expansion, group rules, shard/isolate matrix fields |
| `commands` | CLI boundary behavior for affected/run/install/status/cache-key |
| `schema` | Generate the configuration JSON Schema |
| `error` | Typed user-facing failures and exit propagation |

GitHub-specific event resolution belongs to `.github/actions/affected/action.yml`. It passes explicit `--base` and `--head` values to the Rust command. The direct CLI never guesses event variables.

When changing a module, test its public observable contract: valid example, invalid boundary, original regression, and—where Actions/distribution are involved—the released fixture path described in ADR-0002.
