The crate is split into a library (`nanoom`) and the CLI binary. Every capability of the CLI is callable from Rust.

```toml
# Cargo.toml
[dependencies]
nanoom = "0.1"
tokio = { version = "1", features = ["full"] }
```

---

## Configuration

```rust
use nanoom::Config;
use std::path::Path;

// Load and validate config
let config = Config::load(Path::new("nanoom.config.json"), Path::new("."))?;

// Access a group
let ci = config.get_group("ci")?;
println!("tasks: {:?}", ci.tasks); // ["lint", "test", "build"]
```

### `Config::load(config_path, repo_root) -> Result<Config, Error>`

Parses the JSON file, validates all fields, and returns a typed `Config`. Unknown fields, zero concurrency, empty task lists, and empty rule names are rejected with actionable errors.

### `Config::get_group(&self, name) -> Option<&Group>`

Returns the group if present.

### `Config::groups(&self) -> &HashMap<String, Group>`

All groups.

### `Config::global_dependencies(&self) -> &[String]`

Globs from `globalDependencies`.

### `Config::workspace(&self) -> Option<&WorkspaceConfig>`

Override config for discovery.

## Workspace discovery

```rust
use nanoom::workspace::Workspace;

let ws = Workspace::discover(&config, Path::new("."))?;

// Iterate all projects
for project in ws.all_projects() {
    println!("{} ({})", project.name, project.path.display());
}

// Reverse edges: who breaks when this changes?
let lib = ws.get_project_by_name("@lib/core").unwrap();
println!("dependents: {:?}", lib.dependents); // Vec<ProjectId>
```

### `Workspace::discover(config, repo_root) -> Result<Workspace, Error>`

Discovers projects per the workspace config (pnpm/turbo/nx/yarn layouts, include/exclude globs). Returns a `Workspace` with the project graph.

### `Workspace::all_projects(&self) -> &[Project]`

All projects in discovery order.

### `Workspace::get_project_by_name(&self, name) -> Option<&Project>`

Lookup by package.json `name` field.

### `Project` struct

```rust
pub struct Project {
    pub id: ProjectId,
    pub name: String,
    pub path: PathBuf,
    pub package_json_path: PathBuf,
    pub version: String,                    // from package.json
    pub dependency_specs: Vec<String>,      // all 4 dep kinds, raw specifiers
    pub dependents: Vec<ProjectId>,         // reverse edges (internal only)
}
```

## Affected calculation

```rust
use nanoom::workspace::{Workspace, calculate_affected};
use std::path::Path;

let changed = vec![Path::new("packages/core/src/index.ts").to_path_buf()];

let affected = calculate_affected(
    &ws,
    &changed,
    &config.global_dependencies, // lockfiles etc. short-circuit to "all"
    Path::new("."),
    true,                         // include transitive dependents
);

assert!(!affected.is_empty());
// Returns projects in deterministic (discovery) order
```

### `calculate_affected(ws, changed_paths, global_deps, repo_root, transitive) -> Vec<&Project>`

- `changed_paths`: absolute or relative paths to changed files.
- `global_deps`: globs from `Config::global_dependencies`. If any matches, returns all projects.
- `transitive`: `true` = walk reverse edges transitively (default for CI); `false` = only directly changed projects.

Returns a `Vec<&Project>` in deterministic discovery order.

## Matrix generation

```rust
use nanoom::affected::{calculate, generate_matrix_for_group};

let result = calculate(&config, std::path::Path::new(".")).await?;
if result.has_change {
    let matrix = generate_matrix_for_group(&result, "ci");
    println!("{}", serde_json::to_string(&matrix)?); // {"include":[...]}
}
```

### `calculate(config, repo_root) -> Result<AffectedResult, Error>`

Runs the full detection pipeline (reads event env vars, handles shallow-clone deepening, fork resolution). Returns `AffectedResult`:

```rust
pub struct AffectedResult {
    pub has_change: bool,
    pub groups: HashMap<String, GroupMatrix>,
}
```

### `generate_matrix_for_group(result, group_name) -> Matrix`

Converts affected projects for one group into a GitHub Actions matrix, applying rules (ignore/isolate/shard) and the concurrency cap.

```rust
pub struct Matrix {
    pub include: Vec<MatrixEntry>,
}

pub struct MatrixEntry {
    pub name: String,
    pub path: String,
    pub task: String,
    pub shard: Option<usize>,
    pub isolate: bool,
}
```

## Task execution order

```rust
use nanoom::workspace::topological_sort;

let ordered = topological_sort(ws.all_projects());
// dependencies always come before their dependents
```

### `topological_sort(projects) -> Vec<&Project>`

Kahn's algorithm over internal edges. Cycles are tolerated by appending remaining projects so nothing is silently dropped. Use this to run tasks in the correct dependency order.

## Error handling

All fallible APIs return `Result<T, nanoom::Error>` — a `thiserror` enum covering:

- Config validation errors (unknown fields, zero concurrency, empty task lists, empty rule names)
- Git failures (shallow clone deepening, no common ancestor, fork resolution) — with hints
- Workspace parsing errors (missing package.json, duplicate names)
- Task execution exit codes (wrapped with project context)

```rust
use nanoom::Error;

match Config::load(...) {
    Ok(cfg) => { /* ... */ }
    Err(Error::ConfigValidation { path, message }) => {
        eprintln!("Config error in {}: {}", path.display(), message);
    }
    Err(Error::Git { source, hint }) => {
        eprintln!("Git error: {}. Hint: {}", source, hint);
    }
    Err(e) => eprintln!("Other error: {}", e),
}
```
